# HUJI 52002 Big Data Algorithms & Data Mining Fall 2026

This is the course homepage for Math 52002 (and Masters level 52019) at Hebrew University of Jerusalem taught by Professor Adam Kapelner. The course syllabus can be found [here](https://github.com/kapelner/HUJI_52002_Fall_2026/blob/master/syllabus/syllabus.pdf). We use this [discord channel](https://discord.com/channels/1556341692754567288) for class announcements and discussions. 

## Setting up your Computer

There are heavy tech requirements for this class. I have tried to make a complete setup guide. Start with the guide here: [qmd](https://github.com/kapelner/HUJI_52002_Fall_2026/blob/main/setup_docs/01_linux_git_github_setup.qmd) or [pdf](https://github.com/kapelner/HUJI_52002_Fall_2026/blob/main/setup_docs/01_linux_git_github_setup.pdf) and follow directions to the other files. The last instruction file, `03_software_setup_common` will be updated on a rolling basis as we advance.
