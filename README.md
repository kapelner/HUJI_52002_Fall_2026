# HUJI 52002 Big Data Algorithms & Data Mining Fall 2026

This is the course homepage for Math 52002 (and Masters level 52019) at Hebrew University of Jerusalem taught by Professor Adam Kapelner. The course syllabus can be found [here](https://github.com/kapelner/HUJI_52002_Fall_2026/blob/master/syllabus/syllabus.pdf). We use this [discord channel](https://discord.com/channels/1463307077060526225) for class announcements and discussions. 

## Setting up Linux

If you have MAC or linux already, you are set. If you have Windows, you will need to install WSL. See instructions here as [qmd](install-wsl-ubuntu.qmd) or [pdf](install-wsl-ubuntu.pdf).

## Setting up git and github

We will use Linux/MAC BSD for all work in this class. To hand in assignments you will need git source control and a github repository for sharing code with me and the TA; this is how you will hand in assignments. Instructions for setting up Linux/BSD, git and github can be found here as [qmd](https://github.com/kapelner/HUJI_52002_Fall_2026/blob/main/setup_docs/linux_git_github_setup.qmd) or [pdf](https://github.com/kapelner/HUJI_52002_Fall_2026/blob/main/setup_docs/linux_git_github_setup.pdf).

## Setting up all other Software Needed
